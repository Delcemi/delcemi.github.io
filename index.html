01 About

I build what
runs the game.

Three years on Roblox, seven writing code across platforms. I do both backend and front-end. Combat engines, AI controllers, data pipelines, physics rigs, and the polished UI/web front-ends that sit on top of them. If it runs the game or the interface, I've probably built one.

Everything gets written from scratch, structured properly, and built to not fall apart when things scale up. Critical paths get smoke-tested against staging before going to live, and persistence layers are session-locked so a bad save can't take a player's progress down with it.
